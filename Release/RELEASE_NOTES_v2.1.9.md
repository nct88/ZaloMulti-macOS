# ZaloMulti v2.1.9

## Sửa lỗi

- Gõ **Tên hiển thị** rồi bấm sang **Số điện thoại** thì tên bị xóa, nút Tạo Clone khóa: SwiftUI `TextField` + `@State` + `@FocusState` trên macOS reset chữ khi đổi focus.
- Ô nhập chuyển sang AppKit `NSTextField`; tên/SĐT lưu trên class `AddCloneFormModel` nên không mất khi đổi ô.
- Form vẫn mở bằng cửa sổ riêng (NSPanel).

- `ZaloMulti-2.1.9-Intel.dmg`: Mac Intel
- `ZaloMulti-2.1.9-AppleSilicon.dmg`: chip M
- `ZaloMulti-2.1.9-Universal.dmg`: khuyến nghị
